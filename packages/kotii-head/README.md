### Convenience Components for kotii js

**kotii-head** is that provides app context management, head management, hooks, and reusable components for images and SVGs.

---

## Installation

```bash
npm install kotii-head
# or
yarn add kotii-head
```

## Exports

This package exports several components, hooks, and context utilities:

---

### **Components**

#### **AppProvider**

Provides the application-wide context using the React Context API. Wrap your app with this provider to share global state.

#### **Head**

A React component to declaratively manage `<head>` elements (such as meta tags).

#### **HeadHelmet**

A specialized head management component, compatible with `react-helmet` patterns.

#### **Image**

A reusable image component with potential built-in optimizations.

#### **Svg**

A reusable SVG component that supports inline SVG rendering.

---

### **Hooks**

#### **useAppContext**

Custom hook to access the state and methods provided by `AppProvider`.

#### **useUniversalEffect**

A hook that behaves like `useEffect` but works universally in both client- and server-side rendering environments.
