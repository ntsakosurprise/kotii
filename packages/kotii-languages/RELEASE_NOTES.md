# 📦 kotii-languages — Release Notes

This document tracks all notable changes made to the **kotii-languages** library.  
Adheres to semantic versioning: **MAJOR.MINOR.PATCH**

---

## v1.0.0 — Initial Stable Release

**Date:** 2025-01-01

### 🚀 New Features

- Added **LanguageProvider** for supplying language context across the app.
- Introduced **useLanguage** hook:
  - Access current language
  - Update active language
  - Access translations for the active locale
- Included **LanguageSwitcher** component for simple UI-based language switching.
- Full support for multiple languages and custom translation objects.
- Zero external dependencies — lightweight and framework-friendly.

### 📘 Documentation

- Added README with installation, usage, and API examples.
- Added project roadmap.

### 🧱 Infrastructure

- Bundled package for npm distribution.
- Implemented basic project structure and initial TypeScript types (if applicable).
