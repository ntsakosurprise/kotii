# 📄 Changelog

All notable changes to **kotii-languages** will be documented in this file.  
This project adheres to **Semantic Versioning (SemVer)**.

---

## [1.0.0] — 2025-01-01

### 🎉 Initial Release

- Added `LanguageProvider` for global language context.
- Implemented `useLanguage` hook to access and update language state.
- Included `LanguageSwitcher` component with basic styling.
- Enabled multi-language support with user-defined translation objects.
- Provided initial documentation and usage examples.
- Setup project structure and build pipeline for npm publishing.

---

## [1.0.1] — (Upcoming Patch)

### 🐞 Fixes

- Improve stability for context updates.
- Fix TypeScript definitions for optional provider props.
- Minor internal refactor and cleanup.

---

## [1.1.0] — (Planned Minor Release)

### ✨ Enhancements

- Customizable UI for `LanguageSwitcher`.
- Better error handling for missing translations.
- Optional fallback language support.
- Expanded TypeScript types and improved developer documentation.
