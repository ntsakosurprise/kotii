# Kotii

### Build More. Configure Less.

A next-generation **full-stack JavaScript framework** powered by an event-driven foundation and a plugin architecture built on **Anzii**.

Kotii combines the expressiveness of React, the power of a custom compiler pipeline, and the flexibility of a fully extensible backend — all in a framework that stays simple, intuitive, and incredibly fast.

---

## 🚀 Why Kotii?

### **Full-stack by default**

Create frontend interfaces, backend routes, APIs, server logic, and database operations — all in one unified file-based system.

### **Powered by Anzii**

Kotii inherits a fully event-driven architecture and plugin system from the **Anzii Framework**, enabling deep customization at every layer: build, runtime, dev server, compiler, and routing.

### **React-first, ecosystem-wide vision**

Kotii provides best-in-class React support today, with a long-term roadmap for multi-framework compatibility (Vue, Svelte, Solid, etc.).

### **Lightning-fast DX**

- Instant Hot Module Replacement
- Zero-config setup
- Intelligent reloads
- Built-in DevTools
- Auto asset handling
- Rich markdown pipeline

You spend less time configuring and more time building.
