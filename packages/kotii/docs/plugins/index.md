Kotii plugins are kotiijs' native plugins. These are the plugins that make kotiijs what it is a meta framework. In other words, this is kotiijs' source code. These plugins are based on Anzii js. Anzii js a light-weight backend framework that uses an event driven architecture for writing backend applications.
This document is written as a kind of guidance to the different kotii plugins and how they work.
