# PackageJson Scripts

<h2><strong>What it is?</strong></h2>

<p>The scripts section of kotiijs package.json file</p>

## **Scripts Explained**

- `start` This script runs the production version of a kotiiJS app when executed
- `dev` This script runs the development version of a kotiiJS app when executed
- `build` This script creates a build version of kotiiJS app for production
- `static` This script creates a static website using kotiiJS
- `babel-ssr` This script runs transpilation operations when kotiiJS builds an app for production
