# API Documentation

Below is the full breakdown of all FileRouter methods, categorized for readability.

---

## 🗂️ 1. Initialization & Orchestration

### `init()`

Initializes FileRouter:

- Ensures required directories exist
- Loads saved caches
- Prepares Babel register
- Sets up watchers

### `handleFileRoutes()`

Main entry point for routing generation:

- Extracts pages
- Processes markdown
- Builds router components
- Generates pages + manifest files

### `startAstFlow()`

Starts full AST processing pipeline for all discovered sources.

---

## 📄 2. Page Discovery Methods

### `getPages()`

Scans filesystem and returns:

- List of pages
- List of markdown files
- Metadata for each

### `getSourceCodes(files)`

Reads and returns the text content of a list of files.

### `getItemPath(filepath)`

Returns the **route portion** of the file path.

**Example:**

```js
{
  path: "/blog/hello",
  fileName: "hello.js",
  category: "pages"
}
```

## 4. AST Manipulation Methods

### `addToAST(ast, node)`

Adds an AST node inside a default export block.

### `astAddNode({ ast, node, path })`

Generic AST node adder.

### `astDeleteNode({ ast, target })`

Removes a specified node.

### `addOrRemoveByAST(options)`

Handles conditional AST updates:

- Allows both adding and removing
- Uses previously saved AST references

---

## 📥 5. Import Handling

### `doImports(importsList, additionalImports, code)`

Inserts multiple import declarations into a file.

### `doImport({ node, ast })`

Inserts a single import node.

### `insertImportDeclarations(ast, imports)`

Inserts import statements at the top of the file.

### `removeImportDeclarations(ast, matchFn)`

Removes imports that match a predicate.

### `removeDyanimcImportDeclaration(ast)`

Specifically removes dynamic import declarations generated by FileRouter.

### `insertIdentifierImportDeclarations(ast, identifiers)`

Injects named imports if not already present.

### `isImportSetInAst(ast, sourcePath)`

Checks whether an import is present.

### `isLazyLoadedImportVariable(node)`

Returns `true` if the variable is a lazy-loaded import.
