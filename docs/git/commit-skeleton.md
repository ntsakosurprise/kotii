# Commit Skeleton

<h2 style="color: black">category|type: Here-add a title of your commmit</h2>
<h3>[#123](optional) Here-specify a ticket number reference and a title of the issue it relates to</h3>
<p style="width: 80%">This is the body of your commit, explain the problem or the functionality that the commit adds, and why the change has been implemented. The commit body and the follow up sections are all optional  </p>

<p style="width: 80%">You can add more exlanatory text on follow up paragraphs, but remember, every paragraph should start with an uppercase character. </p>

<p style="width: 80%">You can also use bullet points in your commit message that can be in the following format: </p>

- Bullet point one
- Bullet point two

<h2>fix(commit): enforce standard commit message format</h2>

<p>
  Recent commits lacked clarity and consistency, making it harder to
  understand intent and track changes over time.
</p>

<p>
  This change introduces documented commit guidelines to ensure:
</p>

<ul>
  <li>Descriptive, meaningful subject lines</li>
  <li>Clear commit bodies explaining the rationale</li>
  <li>Consistent formatting across the repository</li>
</ul>
